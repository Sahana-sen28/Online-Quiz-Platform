================================================================================
          QUIZMASTER — ONLINE QUIZ PLATFORM (MINI PROJECT)
================================================================================

Welcome to QuizMaster! This mini-project is a standalone Java Swing desktop 
application connected to an Oracle Database via JDBC.

DOCUMENTATION FILES INCLUDED IN THIS FOLDER:
--------------------------------------------------------------------------------
1. README_ARCHITECTURE_AND_MODULES.txt
   - Explains the 4-layer architecture.
   - Explains all modules (Java Swing, AWT, JDBC, Oracle DB, SHA-256, Maven).
   - Explains WHY each technology was chosen in simple, beginner-friendly terms.

2. PROJECT_WORKFLOW.txt
   - Step-by-step breakdown of how the application runs.
   - User authentication workflow (Admin Login & Student Registration).
   - Admin features workflow (Question CRUD, Student Results, Statistics).
   - Student features workflow (Quiz Setup, Timed Quiz Engine, Auto-scoring, History).
   - Database interaction data flow.


QUICK LAUNCH INSTRUCTIONS:
--------------------------------------------------------------------------------
1. Ensure your Oracle Database is running.
2. Double-click `run.bat` in this folder to launch the application.
